# Roping Ari

Built pages only, served by GitHub Pages: a small browser game and the physics sketches behind it.
Ari rides trolleybus wires on two long poles and ropes over the trolleybuses in her way.

- `index.html` landing page
- `game.html` the game (keyboard)
- `at-speed.html`, `gaits.html`, `first-version.html` the sketches
